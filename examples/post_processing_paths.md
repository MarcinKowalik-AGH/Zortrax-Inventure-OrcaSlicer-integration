# Przykładowe ścieżki post-processingu w Orca

Windows:

```text
C:\Users\<użytkownik>\OrcaScripts\run_g2z_orca_postprocess.bat
```

macOS:

```text
/Users/<użytkownik>/OrcaScripts/run_g2z_orca_postprocess.command
```

W polu Orca najlepiej podawać pełną ścieżkę. Sam launcher potrafi już preferować katalog `OrcaScripts` w katalogu domowym.

# Documentation / Dokumentacja

## Polski

Dokumentacja po polsku znajduje się w katalogu [`docs/pl`](pl/).

Najważniejsze pliki:

- [`INSTALLATION.md`](pl/INSTALLATION.md) — instalacja Windows/macOS i konfiguracja Orca.
- [`FILES.md`](pl/FILES.md) — opis plików repozytorium.
- [`MARKERS.md`](pl/MARKERS.md) — markery `ZORTRAX_*`.
- [`ORCA_METADATA.md`](pl/ORCA_METADATA.md) — metadane Orca używane przez konwerter.
- [`ZCODE_HEADER_AND_MATERIALS.md`](pl/ZCODE_HEADER_AND_MATERIALS.md) — nagłówek `.zcode` i mapowanie materiałów.
- [`GITHUB_PUBLISHING.md`](pl/GITHUB_PUBLISHING.md) — publikacja projektu na GitHubie.

# Polityka dopisków w nazwach presetów

Aktualna polityka: `CANONICAL_PREFIX_PLUS_USER_SUFFIX_ALLOWED`.

Dozwolone są dopiski po nazwie kanonicznej, np.:

```text
Z-PLA test
Z-SUPPORT ATP test
0.15mm Quality @Zortrax Inventure 0.4 nozzle - dual test
Zortrax Inventure 0.4 nozzle - single copy
```

Nie zakładać automatycznego mapowania, jeśli dopisek jest przed nazwą, np. `Test Z-PLA`.

# Profile suffix policy

Current policy: `CANONICAL_PREFIX_PLUS_USER_SUFFIX_ALLOWED`.

Suffixes after canonical preset names are allowed, for example:

```text
Z-PLA test
Z-SUPPORT ATP test
0.15mm Quality @Zortrax Inventure 0.4 nozzle - dual test
Zortrax Inventure 0.4 nozzle - single copy
```

Do not assume automatic mapping when the custom text comes before the canonical name, for example `Test Z-PLA`.
